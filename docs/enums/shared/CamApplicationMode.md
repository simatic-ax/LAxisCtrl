# CamApplicationMode

| Symbol | Value | Description |
| ------ | ----- | ----------- |
| ONCE | DINT#0 | Runs the cam profile once |
| CYCLIC | DINT#1 | Runs the cam profile cyclic (absolute on the following value side) |
| CYCLIC_APPENDING | DINT#2 | Runs the cam profile cyclic (continuously appending on the following value side) |
