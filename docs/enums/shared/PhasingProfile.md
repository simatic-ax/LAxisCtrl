# PhasingProfile

| Symbol | Value | Description |
| ------ | ----- | ----------- |
| DYNAMICS_PARAMETERS | DINT#0 | Leading value offset using dynamic parameters (only applicable for gearing operation) |
| LEADING_VALUE_DISTANCE | DINT#1 | Leading value offset using leading value distance as of current leading value position |
| LEADING_VALUE_DISTANCE_AT_START_POSITION | DINT#2 | Leading value offset using leading value distance as of leading value position StartPosition |
| CANCEL_PENDING_PHASING | DINT#5 | Cancel pending job for leading value offset |
