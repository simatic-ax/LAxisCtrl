# PowerOffMode

| Symbol | Value | Description |
| ------ | ----- | ----------- |
| EMERGENCY_STOP | INT#0 | Using emergency stopping dynamics |
| IMMEDIATE_STOP | INT#1 | Using immediate stopping dynamics (via OFF3 ramp-down time from drive system) |
| MAX_DYNAMICS_STOP | INT#2 | Using maximum stopping dynamics |
| COASTING_DOWN | INT#3 | Coasting down |
